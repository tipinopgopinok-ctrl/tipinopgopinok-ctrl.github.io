Подключить GitHub

Чат хранится в публичном обсуждении этого репозитория. Секреты и токены не сохраняются в браузере.

Как настроить: создайте GitHub OAuth App в Developer settings, включите Device Flow и укажите Client ID. Client secret не нужен и никогда не должен попадать на страницу.

Discussions включены в этом репозитории. После входа выберите категорию для чата. Для OAuth используются разрешения read:user, read:discussion и write:discussion. Подробнее — Device Flow.

Сообщения и стикеры доступны участникам с доступом к Discussions. Все комментарии публичны. Ограничение «около 20» — ориентир, а не техническая блокировка.

Для фото нужен безопасный хостинг

GitHub Discussions принимает текст, но не предоставляет поддерживаемый публичный API для загрузки изображений из статического сайта. Без отдельного сервера здесь нельзя надёжно хранить фото, стикеры-картинки и их комментарии. Мы не будем изображать успешную публикацию или отправлять ваши фото в сторонний сервис.
